Troubleshooting Steps to Resolve:

  1. Verify MySQL Server is running:

    Open Windows Services (services.msc) or MySQL Workbench / XAMPP and verify the MySQL service is started on port 3306.

  2. Configure your .env file:

    Copy .env.example to .env in the project root and fill in your MySQL credentials (DB_USER and DB_PASSWORD).

  3. Initialize the database schema:

    Run python seed.py in your terminal to create the database, tables, and demo records.
